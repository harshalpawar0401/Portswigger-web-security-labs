# PortSwigger Web Security Academy Practice

## About
This repository documents my hands-on learning in web application security using PortSwigger Web Security Academy.

My goal is to develop practical skills relevant to Vulnerability Assessment and Penetration Testing (VAPT).

## Repository Contents
- `progress-tracker.md` — Progress across completed labs.
- Topic folders — Selected detailed lab write-ups and supporting evidence.

## Topics
- SQL Injection
- Authentication
- Access Control
- Cross-Site Scripting
- Server-Side Vulnerabilities
- Other web security topics as I progress

## Learning Approach
I study the vulnerability, practise in authorized training labs, verify my results, and record important findings.

Detailed reports are original write-ups based on my own lab work and include the testing approach, evidence where appropriate, impact, and remediation.

## Disclaimer
All practical testing documented here is conducted in authorized training environments or systems for which permission has been granted.
